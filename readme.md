# Cash-Flow

A simple salary and expense tracker built with plain HTML, CSS and JavaScript. No build step or backend needed.

🔗 **Live Demo:** https://your-username.github.io/cash-flow
💻 **Source Code:** https://github.com/your-username/cash-flow

## Features

- Set your total salary and add or delete expenses
- Remaining balance (salary − expenses) updates instantly
- Alert when the balance falls below 10% of your salary
- Pie chart of remaining balance vs. expenses
- Switch currency: INR, USD, EUR, GBP, JPY (live exchange rates)
- Download a PDF report
- Data is saved in your browser (localStorage)

## Run

Download or clone the project and open `index.html` in any modern browser.
An internet connection is needed for the chart, PDF, fonts and exchange rates.

## Files

`index.html` (layout), `style.css` (styling), `script.js` (app logic)

## Built with

[Chart.js](https://www.chartjs.org/), [jsPDF](https://github.com/parallax/jsPDF) and the [Frankfurter](https://www.frankfurter.app/) API.
